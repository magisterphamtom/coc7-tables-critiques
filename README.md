# CoC7 Tables de critiques

Une **table de conséquences par compétence** pour Call of Cthulhu 7e (système CoC7). Quand un jet est une **réussite critique** ou une **maladresse**, le Gardien tire une conséquence adaptée à la compétence jouée : un pneu crevé en Conduite, une note en marge en Bibliothèque, une arme qui s'enraye en Armes à feu…

## Utilisation
- Sur la carte d'un jet critique ou raté de façon fumble, un bouton **« Conséquence de la réussite critique / de la maladresse »** apparaît, **visible du Gardien seul**.
- Un clic tire dans la table de la compétence et affiche une carte de conséquence dans le chat, aux couleurs du thème choisi dans « CoC7 – Cartes de chat thématiques ». Le bouton **« Retirer »** (Gardien) change le résultat.
- Réglages (Configurer les paramètres → Modules) : **tirage automatique** (à chaque critique ou maladresse, sans bouton) et **qui voit la conséquence** (tout le monde, ou le Gardien seul pour préparer la narration).

## Les tables
Au premier lancement, le module crée dans le monde le dossier **« Critiques et maladresses »** avec 24 tables Foundry (12 familles × réussite critique / maladresse, 8 résultats chacune). Ce sont de vraies tables : modifie, ajoute ou retire des lignes comme tu veux, le module utilise toujours tes versions. Si tu supprimes une table, le module retombe sur son texte d'origine.

| Famille | Compétences reconnues (exemples) |
|---|---|
| Conduite et pilotage | Conduite, Pilotage, Monte à cheval, Navigation |
| Discrétion | Discrétion, Crochetage, Passe-passe |
| Psychologie | Psychologie |
| Bibliothèque | Bibliothèque, Recherches |
| Armes à feu | Armes à feu (pistolet, fusil…) |
| Combat rapproché | Bagarre, Arme blanche, Combat rapproché |
| Compétences sociales | Baratin, Persuasion, Charme, Intimidation |
| Perception | Écouter, Trouver objet caché, Pister |
| Soins et médecine | Premiers soins, Médecine |
| Savoirs et sciences | Occultisme, Histoire, Archéologie, Mythe de Cthulhu, Langues… |
| Prouesses physiques | Grimper, Sauter, Nager, Esquive, Lancer |
| Compétence quelconque | toutes les autres |

Les textes sont écrits pour convenir aussi bien en 1933 qu'en 2026.

## Installation
Foundry → Modules → Installer un module, puis colle le lien du manifeste :
```
https://github.com/magisterphamtom/coc7-tables-critiques/releases/latest/download/module.json
```
Compatible Foundry v13 et v14, système CoC7 (8 et plus). Complète bien le module **Critiques du Mythe** (effet visuel et sonore), mais fonctionne sans lui.

---
*English: a consequence table for each CoC7 skill, drawn on a critical success or fumble. The Keeper gets a button on the roll card (or enable automatic draws in the module settings). Tables are regular Foundry RollTables created in a “Critiques et maladresses” folder and can be edited freely. The text is in French.*
